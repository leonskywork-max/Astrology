# Продуктовая спецификация astro-bot

## Позиционирование

Не "ещё один астроканал", а персональный астролог в кармане с характером. Целевая аудитория: городские женщины 20–40, образованные, скептичные к традиционной эзотерике, но открытые к самоисследованию через астрологию-как-психологию.

Главный дифференциатор: **тон**. Жёсткий, ироничный, прямой, временами хлёсткий. Не "сегодня день благоприятен для новых начинаний", а "ретроградный Меркурий — это не повод писать бывшему". Эталон — Co-Star, адаптированный под русскоязычную культуру.

Визуальная эстетика: минимализм. Чёрный/тёмный фон, белый текст, без розовых звёзд, кристаллов и хрустальных шаров. Отделяет от 90% русскоязычных астроканалов.

## Архитектура продукта

Три связанные сущности:

**Канал** — массовый вход, охват, рекламная монетизация. Ежедневный пост в 8:00.

**Бот** — ядро продукта. Персонализация, push-уведомления, подписка.

**Mini App** (фаза 2) — визуализация натальной карты, графики транзитов, синастрия.

## Функционал бота

### MVP (фаза 1, недели 1–4)

Онбординг:
- Приветствие в фирменном тоне
- Запрос даты рождения
- Запрос времени рождения (опционально, с объяснением зачем)
- Запрос места рождения (через геокодинг)
- Расчёт натальной карты через swisseph
- Первичный портрет личности (3–4 абзаца в фирменном тоне)

Бесплатные функции:
- Карта Таро дня (1 раз в день, бесплатно)
- Гороскоп дня по солнечному знаку (но с фирменным тоном)
- Совместимость с другим пользователем (виральная функция)
- Базовый портрет личности (Солнце, Луна, Асцендент)

Премиум-функции (подписка):
- Ежедневный персональный push в 8:00 на основе транзитов к натальной карте
- Полная натальная карта с интерпретацией по сферам
- Прогноз на неделю/месяц/год
- Синастрия (глубокий разбор отношений с другим человеком)
- Безлимитные расклады Таро
- Дневник состояний с астрологическим контекстом
- Отключение рекламы

### Фаза 2 (месяцы 2–4)

- Mini App с визуализацией натальной карты
- Pay-per-reading: глубокие разовые разборы (299–999₽)
- Push при важных транзитах (не только утренний)
- Реферальная программа

### Фаза 3 (месяцы 4–12)

- Live-консультации с астрологами (marketplace, комиссия 30%)
- Расширенные техники: астрокартография, прогрессии, соляр
- Партнёрские интеграции с эзо-товарами

## Тарифы

- Free: онбординг, базовый портрет, карта Таро дня, гороскоп дня, 1 совместимость в неделю
- Premium: 399₽/мес или 2990₽/год (триал 7 дней)
- Pay-per-reading: 299–999₽ за глубокий разовый разбор

## Монетизация — три потока

1. Подписка Premium (основа)
2. Реклама в канале (масштабируется с ростом канала)
3. Pay-per-reading + партнёрские продажи (карты Таро, курсы, психологи)

## Ключевые продуктовые принципы

**Push — главный продукт, не функция.** Утренний пуш — это не уведомление о том, что в боте что-то есть. Это и есть продукт. Бот = сообщения, которые приходят сами. Пользователь не должен заходить в бот, чтобы получить ценность.

**Compatibility — виральная функция №1.** Должна быть на видном месте в онбординге. Каждый расчёт совместимости — это shareable ссылка для приглашения партнёра/друга.

**Тон важнее точности.** Лучше меткое и спорное наблюдение, чем общая и безопасная фраза. Скучный бот не вирусится.

**Минимум кнопок в интерфейсе.** Бот общается текстом. Кнопки только там, где они правда нужны (выбор расклада, оплата). Никаких меню из 15 пунктов.

## Технический стек

- Node.js + Telegraf или Python + aiogram (выбор по предпочтению агента)
- PostgreSQL для пользователей и истории
- pyswisseph (если Python) или swisseph-via-bindings (если Node) для астрорасчётов
- Anthropic Claude API для генерации интерпретаций (Sonnet 4 для качества, Haiku 4.5 для массовых задач типа гороскопов)
- Telegram Stars для платежей (для МСНГ) + ЮKassa/CloudPayments (для РФ)
- Деплой на Railway (уже настроен в workspace)
- Supabase как альтернатива для БД (уже есть в SERVICES)
