# Roadmap astro-bot

Задачи разбиты по фазам, не по дням. Внутри фазы задачи можно делать параллельно. Каждая задача = отдельная ветка `agent/<task-id>`.

## Фаза 0. Стратегия и подготовка

### task-001: Конкурентный анализ ✅
Собрать 30 топовых русскоязычных астрологических Telegram-каналов и ботов. По каждому зафиксировать: позиционирование, ToV, аудиторию, контент-форматы, монетизацию, слабые места. Результат: `knowledge/competitors.md`.

**Сделано 2026-05-17.** Найдено 48 источников (34 канала + 14 ботов). Главный вывод: ниша Co-Star-стиля занята **частично, но не там, где опасно** — голос есть без продукта (Ретроградный Меркурий, гороскоп и кирилл), продукт есть без голоса (Numia, Natalon, Hey Mira). Между этими полюсами — пусто, туда и заходим. Топ-3 прямых конкурента: Numia (10M+), Natalon (премиум 100₽/мес — пересмотреть монетизацию), Hey Mira. Главный риск: если "Ретроградный Меркурий" или "гороскоп и кирилл" запустят бота — щель закроется.

### task-002: Финализация позиционирования ✅
На основе конкурентного анализа уточнить нишу. Сравнить варианты: "астрология для скептиков", "жёсткий Co-Star-стиль", "астрология + психология". Выбрать один. Результат: `docs/POSITIONING.md`.

**Сделано 2026-05-18.** Выбран **вариант A — "Co-Star на русском"**: острый персональный голос против wellness-приторности. Целевая аудитория — городские женщины 22–35. Премиум 399₽/мес (оправдывается голосом, не объёмом). Запуск канала/бота — только после MVP. Полная спека в `docs/POSITIONING.md`.

### task-003: Нейминг ✅
Сгенерировать 20 вариантов названий канала и бота, отфильтровать по доступности username в Telegram. Выбрать финальное. Результат: запись в `MEMORY.md`.

**Сделано 2026-05-18.** Бренд — **Numen** (лат. "знак свыше"). Канал — `@heynumen` (в стиле Hey Mira), бот — `@numenapp`. Короткий @numen оказался на аукционе fragment.com, как и почти все короткие "красивые" имена — для них нужна покупка $500–5000+. Сохраняем бренд через составной username. История 4 кругов проверки (≈150 username) в `knowledge/naming_options.md`. Финальная запись в `MEMORY.md`.

### task-004: Айдентика ✅
Сгенерировать через AI: логотип, аватар канала, обложка, шаблоны постов, цветовая схема (тёмная). Результат: `content/branding/`.

**Сделано 2026-05-18.** Зафиксирован Brand Guide в `docs/BRAND.md` (палитра с HEX-кодами, типографика Playfair Display + Inter, принципы минимализма, do/don't, антитеза розово-эзотерическому). Свежеcоздан `content/branding/` с тремя подпапками:
- `prompts/` — готовые промпты для Midjourney/DALL-E (аватары, обложка, шаблоны постов, иконография)
- `logo/` — SVG-прототипы (3 варианта аватара, wordmark, обложка канала). Это отправные точки для дизайнера
- `templates/` — шаблоны постов канала под все 7 дней недели (HTML + визуальные правила)

Финальные растровые ассеты (PNG для Telegram-аватара, обложки) — задача для дизайнера или для Леона через Midjourney/Figma.

## Фаза 1. MVP бота

### task-101: Скаффолдинг проекта ✅
Создать `src/` со структурой: bot/, db/, astro/, llm/, payments/. Базовый Telegraf/aiogram, hello-world команды, подключение к БД, env-конфиг. Коммит после каждого добавленного модуля. Результат: рабочий бот, отвечающий на /start.

**Сделано 2026-05-18.** Стек: TypeScript 5.7 + Telegraf 4.16 + Supabase JS + Anthropic SDK + pino + tsx. Node 20+. Структура `src/` по STACK.md (bot/, astro/, llm/, db/, payments/, jobs/, analytics/, utils/). Команды `/start`, `/chart`, `/help` работают. Заглушки с типами в astro/chart.ts (контракт для task-102), llm/claude.ts, db/client.ts. Миграции SQL для всех 7 таблиц в src/db/migrations/0001_initial_schema.sql (применять через Supabase Dashboard вручную). Smoke test пройден — config валидируется, бот инициализируется, Telegram API доступен (с реальным BOT_TOKEN стартует). README обновлён с инструкциями запуска.

### task-102: Интеграция swisseph ✅
Подключить библиотеку астрорасчётов. Реализовать функцию: вход — дата/время/место, выход — позиции 10 планет, дома, аспекты. Юнит-тесты на известных картах (например, карта Юнга, чтобы сверить с астропроцессором). Результат: `src/astro/chart.js` или `src/astro/chart.py`.

**Сделано 2026-05-18.** Пакет `sweph` (Swiss Ephemeris bindings) + luxon для tz. Moshier fallback вместо файлов эфемерид (точность ±10 arcsec, достаточно для астрологии). Реализовано: `src/astro/ephemeris.ts` (обёртка над sweph), `src/astro/zodiac.ts` (длины→знаки, форматирование RU/EN), `src/astro/aspects.ts` (5 мажорных аспектов с орбами 6-8°, расширенные для люминариев), `src/astro/chart.ts` (calculateChart полный). Тест на карте Юнга (1875-07-26, Кессвиль): Sun, Moon, аспекты совпали с эталоном (Sun square Neptune orb 0.27°, Jupiter trine Saturn orb 0.40°). ASC/MC имеют ~4° сдвиг для исторических дат (известный edge case IANA tz vs LMT), для современных дат не проблема.

### task-103: Геокодинг ✅
Подключить API для перевода "Москва" → координаты + таймзона. Варианты: OpenStreetMap Nominatim (бесплатно), Google Maps API. Результат: `src/astro/geocode.js`.

**Сделано 2026-05-19.** `src/astro/geocode.ts` с OpenStreetMap Nominatim (бесплатно, без API ключа) + `tz-lookup` (статичная карта tz без API). User-Agent по ToS. AbortSignal.timeout 10s. Возвращает null если место не найдено, осмысленные ошибки при таймауте/non-200. Тест на 8 местах (Москва, Ковров, Питер, Владивосток, Тбилиси, Нью-Йорк, Kesswil, несуществующее) — все pass. Для production-масштабирования (>10K юзеров/день) добавить кеширование результатов в БД + fallback на Google Maps API.

### task-104: Онбординг ✅
Сценарий: /start → приветствие → дата → время → место → расчёт → первичный портрет. Состояние пользователя в БД. Результат: `src/bot/onboarding.js`.

**Сделано 2026-05-19.** Полный conversational flow: state machine в users.state (JSON, переживает рестарты). Шаги: /chart → дата → время (с опцией "не знаю") → место → подтверждение → calculate → save → краткий портрет. Парсеры даты/времени гибкие (RU + ISO + slash форматы). Новые модули: `src/db/users.ts`, `src/db/charts.ts`, `src/bot/parsers.ts`, `src/bot/portrait.ts`. End-to-end тест прошёл на Леоне: 1998-01-06 12:30 Владимир → Солнце в Козероге 15.86°, Луна в Овне 26.28°, Восход в Тельце 19.16°, 15 аспектов сохранены в JSONB. Полный портрет в фирменном тоне через LLM — task-105 + task-109.

### task-105: Промпт-инжиниринг базового портрета
Системный промпт для генерации первичного портрета на основе натальной карты. Минимум 50 тестовых прогонов на разных картах, проверка качества, итерации. Эталон тона см. `prompts/TONE.md`. Результат: `prompts/natal_portrait.md`.

### task-106: Карта Таро дня
Колода Таро (78 карт) с интерпретациями в фирменном тоне. Один пуш в день в фиксированное время или по запросу. Результат: `src/bot/tarot.js` + `knowledge/tarot_deck.md`.

### task-107: Гороскоп дня по солнечному знаку
Ежедневная генерация 12 коротких гороскопов на основе текущих транзитов. Запуск по cron в 7:30 утра. Кеш в БД. Результат: `src/jobs/daily_horoscopes.js`.

### task-108: Совместимость (виральная функция)
Сценарий: пользователь нажимает "узнать совместимость" → бот выдаёт ссылку для шеринга → партнёр переходит → онбординг для партнёра → оба получают разбор пары. Метрика: viral coefficient. Результат: `src/bot/compatibility.js`.

### task-109: Подключение Claude API
Обёртка для вызовов с retry, fallback Haiku → Sonnet при сложных задачах, логирование стоимости. Результат: `src/llm/claude.js`.

### task-110: Платежи
Telegram Stars для международной аудитории, ЮKassa для РФ. Подписка и разовые покупки. Webhook для активации Premium. Результат: `src/payments/`.

### task-111: Премиум-логика
Проверка статуса подписки перед каждым премиум-действием. Триал 7 дней при первой оплате. Auto-renewal. Результат: `src/payments/subscription.js`.

### task-112: Ежедневный персональный push (Premium)
Cron-задача в 8:00 (в таймзоне пользователя): рассчитать транзиты к натальной карте → сгенерировать короткий персональный текст → отправить. Это главный retention-механизм. Результат: `src/jobs/daily_push.js`.

### task-113: Аналитика с первого дня
Логировать в БД: регистрация, активация (прошёл онбординг), DAU/WAU/MAU, retention D1/D7/D30, конверсия в подписку, источник трафика. Дашборд через Metabase или Supabase Studio. Результат: `src/analytics/`.

### task-114: Деплой MVP на Railway
CI/CD через GitHub Actions: push в main → деплой. Env-переменные через Railway dashboard. Healthcheck. Результат: рабочий бот в production.

## Фаза 2. Контент-машина для канала

### task-201: Контент-план на 30 дней
Структура постов по дням недели. Шаблоны под каждый тип. Результат: `content/PLAN_M01.md`.

### task-202: Промпты для контента канала
Системные промпты для генерации постов в фирменном тоне. Отдельные промпты под форматы: гороскоп недели, разбор аспекта, мем, большой пост, рефлексия. Результат: `prompts/content_*.md`.

### task-203: Шаблоны визуалов
Canva/Figma-шаблоны под каждый формат поста. Автозаполнение через API. Результат: `content/visuals/`.

### task-204: Контент-буфер на 30 дней
30 готовых постов до запуска канала. Используются как стартовый контент + резерв на случай простоя. Результат: `content/buffer/`.

### task-205: Автопубликация
Cron-задача: публикация постов из буфера по расписанию. Защита от пустого буфера (алерт в админ-чат). Результат: `src/jobs/channel_publisher.js`.

## Фаза 3. Запуск и трафик

### task-301: Лендинг бота
Простой landing page (Vercel) с описанием продукта, скриншотами, отзывами. Конверсия на t.me/<bot>. Результат: `landing/` (отдельный субпроект).

### task-302: Список каналов для посевов
Через TGStat собрать 100 каналов: эзотерика, женский лайфстайл, психология. Фильтр по ER, накруткам. Результат: `content/seeding_list.csv`.

### task-303: Креативы для посевов
5 вариантов рекламных постов с разными офферами. A/B тест. Результат: `content/ads/`.

### task-304: Запуск посевов
Первая волна 50–100k₽. Замер: CPM, CPC, CPA (стоимость регистрации в боте). Результат: запись в `memory/`.

### task-305: Внешний трафик
Аккаунты в Instagram Reels и TikTok. Ежедневные ролики с гороскопами в фирменном тоне. AI-генерация сценариев. Ссылка на бот в шапке. Результат: контент-конвейер.

### task-306: Партнёрства
Список астрологов-блогеров (5–50k подписчиков) для коллабораций. Им — процент с продаж или бесплатный Premium на месяц. Результат: `content/partners.md`.

## Фаза 4. Масштабирование

### task-403: Реклама в канале
Прайс-лист, форма заявок, фильтрация рекламодателей. Подключение к Telega.in. Результат: `docs/AD_RATES.md`.
