# astro-bot

Telegram-бот с персональной астрологией в стиле Co-Star для русскоязычной аудитории. Концепция: жёсткий ироничный тон, ежедневные персональные пуши, вирусная функция совместимости, минималистичный визуал.

## Аналоги и бенчмарки

Co-Star (US): ~$400K/мес выручки, 30M+ зарегистрированных юзеров, 25% американских женщин 18–25 установили приложение. Главные отличия: NASA-данные + ироничный тон + персональные push-уведомления.

Nebula: ~$99K/мес в US, модель pay-per-reading + чат с астрологами.

The Pattern: глубокие психологические тексты, сессии в 2–4 раза длиннее средних.

Astrotalk (India): $120M+/год, marketplace астрологов.

Глобальный рынок астроприложений: $4 млрд в 2024, прогноз $29 млрд к 2033 при CAGR 24.93%.

## Гипотеза

Русскоязычный сегмент Telegram содержит платёжеспособную аудиторию (Gen Z + Millennials), но лидера в формате Co-Star нет. Существующие каналы пишут приторно и generic, мобильных приложений уровня Co-Star на русском нет. Telegram-формат превосходит мобильное приложение по push-механике (нативные сообщения вместо борьбы за notification slot).

## Целевые метрики 12 месяцев

- Канал: 100–250k подписчиков
- Бот: 80–200k пользователей
- Конверсия в платную подписку: 8–15%
- ARPU: 350–500₽/мес
- Выручка подписок: 2–8M₽/мес
- Реклама в канале: 300k–1M₽/мес
- Чистая прибыль: 1–3M₽/мес

## Структура проекта

- `docs/` — продуктовая спецификация, roadmap, ToV-гайд
- `prompts/` — системные промпты для LLM-генерации
- `content/` — контент-планы канала, шаблоны постов
- `knowledge/` — база знаний по астрологии и Таро
- `memory/` — рабочие заметки по проекту
- `src/` — код бота (заполняется по мере разработки)
