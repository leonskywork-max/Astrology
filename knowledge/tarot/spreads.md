# Расклады Таро — база знаний astro-bot

Расклад = позиции карт в определённой последовательности, каждая позиция имеет своё значение. Карта в позиции "прошлое" читается иначе, чем та же карта в позиции "что мешает". База раскладов для бота — от простых (1 карта) до многослойных (10 карт). Каждый расклад имеет применение, длительность чтения, целевую аудиторию (free / premium).

## Принципы

1. **Случайность с весом.** Старшие арканы (22) выпадают чаще на 30%, чем младшие (56), — для шеринговой способности. (Технически: при генерации использовать weighted random, не uniform.)
2. **Перевёрнутые карты.** В колоде 50% вероятность перевёрнутой. Не игнорировать — это половина смысла.
3. **Один расклад в день.** Free-user: 1 расклад в день. Premium: безлимит. Это не баг ограничения, это правило ритуала — слишком частые расклады обесценивают.
4. **Каждый расклад — единый текст.** Не "карта 1 значит X, карта 2 значит Y". Связное чтение, где карты взаимодействуют.

## Free-расклады

### 1. Карта дня (1 карта)

**Когда:** утро (по запросу или автоматически в 8:00 для подписчиков на канал).
**Позиция:** "Что сегодня".
**Длина текста:** 200–400 знаков.
**Тон:** см. примеры в `major_arcana.md` и `minor_arcana.md`. Конкретно, метко, без сладкого.

**Промпт для LLM:**
```
Сгенерируй текст карты дня для пользователя.
Карта: {название}, {положение — прямая/перевёрнутая}.
Сегодня: {Луна в знаке X, фаза Y}.
Контекст пользователя: {если есть данные о дне рождения — учти Луну в его карте}.
Тон: см. TONE.md. 200–400 знаков. Прямо, конкретно, без эзо-лексики.
Закончи сильно — одним наблюдением, которое хочется заскринить.
```

### 2. Карта на вопрос (1 карта)

**Когда:** пользователь задаёт вопрос текстом, бот тянет одну карту.
**Позиция:** "Ответ на вопрос".
**Длина:** 300–500 знаков.
**Тон:** прямой, отвечающий на вопрос.

**Промпт:**
```
Пользователь задал вопрос: "{вопрос}".
Выпала карта: {название}, {положение}.
Сгенерируй ответ через символику карты.
Не давай конкретных предсказаний (не "встретишь его 15 марта").
Дай психологический угол — что увидеть, что сделать, что отпустить.
200–500 знаков.
```

## Premium-расклады

### 3. Прошлое—Настоящее—Будущее (3 карты)

**Когда:** базовый расклад для размышления над ситуацией.
**Позиции:**
1. Прошлое — откуда это идёт
2. Настоящее — что сейчас
3. Будущее — куда движется (если ничего не менять)

**Длина текста:** 600–1000 знаков.
**Структура чтения:** не отдельно по картам, а как история — "вот откуда это всё началось (карта 1), сейчас ты в этой точке (карта 2), и если не вмешаешься — придёшь сюда (карта 3)".

### 4. Ситуация—Препятствие—Совет (3 карты)

**Когда:** пользователь застрял, нужна ясность.
**Позиции:**
1. Ситуация — что на самом деле
2. Препятствие — что мешает
3. Совет — что делать

**Длина:** 600–1000 знаков.

### 5. Расклад "Подкова" (5 карт)

**Когда:** для конкретной ситуации.
**Позиции:**
1. Прошлое
2. Настоящее
3. Скрытые влияния
4. Совет
5. Возможный исход

**Длина:** 1000–1500 знаков.

### 6. Расклад на отношения (5 карт)

**Когда:** премиум-функция, разбор пары через Таро (дополняет синастрию).
**Позиции:**
1. Ты в этих отношениях
2. Партнёр в этих отношениях
3. Что вас соединяет
4. Что разделяет
5. Куда это движется

**Длина:** 1200–1800 знаков.

### 7. Расклад "Кельтский крест" (10 карт)

**Когда:** глубокий разбор, премиум, по запросу.
**Позиции:**
1. Сама ситуация
2. Что пересекает (помогает или мешает)
3. Основа ситуации (что под ней)
4. Прошлое
5. Возможное будущее
6. Ближайшее будущее
7. Ты в ситуации (как себя ощущаешь)
8. Окружение (как видят другие)
9. Надежды и страхи
10. Финальный исход

**Длина:** 2500–4000 знаков. Это уже близко к лонгриду.

**Цена в pay-per-reading:** 499–799₽.

### 8. Расклад на год (12 карт)

**Когда:** глубокий годовой расклад, премиум-функция, делается раз в году (день рождения или Новый год).
**Позиции:** одна карта на каждый месяц.
**Длина:** 3000–5000 знаков.
**Цена:** 799–1499₽.

### 9. Расклад на чакры / на сферы жизни (7 карт)

**Когда:** диагностический расклад на состояние человека.
**Позиции:** 7 сфер — здоровье, отношения, работа, деньги, творчество, рост, духовность.
**Длина:** 1500–2500 знаков.

## Алгоритм генерации расклада

```
1. Пользователь выбирает расклад из меню
2. Бот:
   a. Тянет нужное число карт (без повторов)
   b. Для каждой карты случайно определяет прямую/перевёрнутую (50/50)
   c. Собирает контекст: даты, позиции, какие карты выпали
   d. Загружает в LLM-контекст: TONE.md + major_arcana.md + minor_arcana.md + spreads.md
   e. Генерирует единый связный текст
   f. Сохраняет результат в tarot_readings таблицу
3. Бот отправляет пользователю
```

## Формат сообщения

```
[Эмодзи карт или ASCII-разделитель]
**Расклад: <название>**

[Карта 1]: <Название> [(перев)]
[Карта 2]: <Название>
...

---

[Связный текст чтения]

---

(для премиума: кнопка "сохранить в дневник" → запись в history)
```

## Что НЕ делать в раскладах

- **Не пугать.** Даже если выпали 3 Мечей + Башня + Дьявол — это не "тебе конец". Это "вот что разваливается, вот почему, вот что делать".
- **Не предсказывать конкретно.** Не "встретишь Ивана через 2 недели". Можно: "Готовься к встрече, которая поменяет тебя — она ближе, чем кажется".
- **Не давать медицинских/финансовых советов.** "Не лечи депрессию таро." Если карта выпадает на тему здоровья — мягко указать на сферу, не диагностировать.
- **Не игнорировать перевёрнутые.** Они не "плохие", они показывают другую грань той же карты.
- **Не делать длинно из ничего.** Один лишний абзац убивает силу — лучше плотно, чем растянуто.

## Промпты для разных раскладов

Промпты для каждого расклада хранятся в `prompts/tarot_<spread>.md` (то есть `prompts/tarot_one_card.md`, `prompts/tarot_celtic_cross.md` и т.д.). Этот файл — структура знаний; конкретные промпты — отдельно, чтобы можно было редактировать без правки базы.

## Виральность через Таро

Расклады хорошо ширятся, если:

1. **Хлёсткий заголовок:** "Расклад на этот месяц" с одной мощной фразой
2. **Скриншот-friendly формат:** компактный, на один экран
3. **Финальная фраза:** что-то, что хочется переслать
4. **Кнопка "поделиться":** генерирует красивый текст для пересылки с упоминанием бота

Это превращает каждый расклад в потенциальный пост у пользователя.
