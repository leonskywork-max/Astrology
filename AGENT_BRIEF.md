# Инструкция IIA: старт проекта astro-bot

Этот файл — точка входа для агента. Прочти его, затем читай файлы в порядке, указанном ниже.

## Что прочитать в первую очередь

1. `README.md` — концепция, цели, метрики
2. `docs/PRODUCT.md` — продуктовая спецификация
3. `prompts/TONE.md` — главный документ, эталон стиля, без которого продукт не существует
4. `docs/ROADMAP.md` — задачи по фазам
5. `docs/STACK.md` — технический стек и архитектура

## Контекст

Аналоги в мире: Co-Star ($400K/мес, 30M+ юзеров), Nebula, The Pattern. Рынок астроприложений $4 млрд в 2024 → прогноз $29 млрд к 2033. В русскоязычном Telegram свободна ниша Co-Star-стиля: жёсткий ироничный тон, минимализм, персональные push, виральная совместимость.

Главная гипотеза: Telegram-формат превосходит мобильное приложение по push-механике (нативные сообщения вместо борьбы за notification slot iOS/Android).

## Что от тебя нужно прямо сейчас

Не начинай сразу с кодинга. Выполни задачи фазы 0 в указанном порядке:

### task-001: Конкурентный анализ
- Найди 30 топовых русскоязычных астрологических Telegram-каналов и ботов
- Для каждого зафиксируй: позиционирование, ToV, аудиторию, контент-форматы, монетизацию, слабые места
- Используй TGStat для верификации цифр аудитории и ER
- Результат сохрани в `knowledge/competitors.md`
- Отдельно отметь топ-3 ботов с похожим функционалом (особенно если есть синастрия, натальная карта, ежедневные push) — это прямые конкуренты, разбор должен быть детальный

### task-002: Финализация позиционирования
- На основе конкурентного анализа предложи 3 варианта финального позиционирования
- Для каждого: целевая аудитория, отличие от конкурентов, риски
- Покажи мне сравнительную таблицу, жди моего выбора
- После выбора — оформи финальное позиционирование в `docs/POSITIONING.md`

### task-003: Нейминг
- Сгенерируй 30 вариантов названия. Критерии:
  - 5–10 символов
  - Легко произносится по-русски и по-английски
  - Намёк на астрологию или личность, но без банальности (не "Astro", не "Stars", не "Cosmos")
  - Username доступен в Telegram (проверь все 30)
- Покажи мне топ-10 с доступными username, жди выбора
- Запомни выбранное в MEMORY.md

### task-004 (после моего апрува нейминга): Айдентика
- Сгенерируй через AI: логотип, аватар канала, обложка канала, цветовая схема
- Стиль: тёмный фон, белый/контрастный текст, минимализм, антитеза розово-эзотерической эстетике
- Шаблоны постов канала (3–5 шт под разные форматы)
- Сохрани в `content/branding/`

## Что НЕ делать сейчас

- Не начинай писать код бота
- Не наполняй базу знаний по астрологии (это task-105 и далее)
- Не запускай посевы
- Не создавай каналы или ботов в Telegram до моего апрува нейминга

## Принципы работы в этом проекте

- Каждая задача = отдельная ветка `agent/task-XXX-<short-name>`
- Коммить после каждого осмысленного шага
- Все промпты для LLM — только в `prompts/`, не в коде
- Промпты после правки → прогоняй на 10+ тестовых данных перед апрувом
- Если задача 3+ шагов — покажи план до выполнения (согласно CLAUDE.md)
- Всё критичное по проекту — в `memory/YYYY-MM-DD.md` ежедневно

## Бенчмарки качества для текстов

После любой LLM-генерации (портрет, push, совместимость, контент канала) проверь:
1. Прошло ли проверку по стоп-словам (`prompts/TONE.md`)?
2. Конкретные астрологические утверждения есть или общие слова?
3. Хочется ли заскринить и переслать?
4. Звучит ли это как Co-Star или как любой ChatGPT?

Если все 4 ответа "да" — выдача готова. Если хоть один "нет" — итерируй промпт.
