# 2026-05-18 — task-004 закрыта (айдентика, финал фазы 0)

## Что сделано

Создан полный пакет айдентики для бренда Numen. Дизайнерские ассеты не финальные — это **отправные точки**, у меня нет инструмента генерации картинок. Леон или дизайнер берёт промпты, прогоняет в Midjourney/Figma, доводит до финала.

## Артефакты

### Brand Guide
- [`docs/BRAND.md`](../docs/BRAND.md) — палитра (HEX-коды), типографика, принципы, do/don't, источники вдохновения, что должен прочитать дизайнер

### Палитра (зафиксирована)
- `#0A0A0A` — Background dark (мягкий чёрный, не чистый)
- `#F5F5F0` — Foreground light (тёплый off-white)
- `#8A8A85` — Muted text
- `#1A1A1A` — Surface elevated
- **Акцент: Numen Gold `#C9A961`** (выбран как основной)
- Альтернативный акцент: Bloodletting Red `#E63946` (запасной, не использовать одновременно)

### Типографика
- **Headline:** Playfair Display (Bold, Black) — для заголовков, логотипа, цитат
- **Body:** Inter (Regular/Medium/Semibold) — для основного текста
- **Mono (опционально):** JetBrains Mono или IBM Plex Mono — для данных и цифр

## Открытые вопросы для Леона

1. **Выбрать акцентный цвет окончательно:** Numen Gold `#C9A961` или Bloodletting Red `#E63946`. Я выбрал Gold (мягче, реже встречается в эзо-визуале), но Red тоже работает под Co-Star-стиль.

2. **Прогнать промпты через Midjourney/Figma** — выбрать финальный логотип и обложку. Можно делегировать дизайнеру (даже фрилансеру за пару тысяч рублей) или сделать самому за вечер с Midjourney.

3. **Конвертация SVG → PNG** для Telegram: для аватара канала нужен PNG 640×640, для обложки — PNG 1280×640. Можно через Figma, Inkscape, или `rsvg-convert`.

4. **Установить аватар канала и бота в Telegram** после готовности PNG — это последний шаг task-004, делает Леон со своего аккаунта.
