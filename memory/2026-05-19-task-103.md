# 2026-05-19 — task-103 закрыта (геокодинг)

## Что сделано

Конвертация строкового места рождения ("Москва", "Kesswil, Switzerland") в координаты и IANA таймзону. Без API-ключей, бесплатно, на чистом fetch.

## Файлы

- [`src/astro/geocode.ts`](../src/astro/geocode.ts) — `geocode(place, language)` → `GeocodingResult | null`
- [`scripts/test_geocode.mjs`](../scripts/test_geocode.mjs) — тест на 8 местах

## Стек

- **OpenStreetMap Nominatim** — геокодинг (place → lat/lng). Бесплатно, без API key, rate limit 1 req/sec
- **tz-lookup** — IANA timezone по lat/lng. Статичная встроенная карта, без API
- **Встроенный fetch + AbortSignal.timeout** — Node 22 native

## Тесты

Все 8 пройдены: Москва, Ковров, Питер, Владивосток, Тбилиси, Нью-Йорк, Kesswil, несуществующее место.

## Важные детали

- **User-Agent** обязателен по Nominatim ToS
- **Rate limit Nominatim** = 1 req/sec. Для масштабирования — кеш в БД
- **AbortSignal.timeout(10_000)** — 10 секунд максимум
