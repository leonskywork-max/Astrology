# 2026-05-18 — task-102 закрыта (swisseph)

## Что сделано

Полная реализация расчёта натальной карты. Использует Swiss Ephemeris через npm-пакет `sweph`. Тест на эталонной карте Юнга проходит.

## Файлы

- [`src/astro/ephemeris.ts`](../src/astro/ephemeris.ts) — обёртка над sweph: `toJulianDay()`, `getPlanetPosition()`, `getHouses()`, `houseOf()`
- [`src/astro/zodiac.ts`](../src/astro/zodiac.ts) — знаки зодиака (en + ru), `longitudeToSign()`, `formatPosition()`
- [`src/astro/aspects.ts`](../src/astro/aspects.ts) — `findAspects()`, 5 мажорных аспектов (conj, sextile, square, trine, opposition) с орбами 6° (8° для люминариев)
- [`src/astro/chart.ts`](../src/astro/chart.ts) — полная реализация `calculateChart()`: 10 планет + Лилит + узел + дома + ASC + MC + аспекты
- [`scripts/test_chart_jung.mjs`](../scripts/test_chart_jung.mjs) — эталонный тест Юнга

## Технические решения

- **Эфемериды:** Moshier fallback (без внешних файлов). Точность ±10 arcsec.
- **Tz:** luxon с IANA timezone. Современные даты — точно. Исторические (до ~1900) — известный edge case (LMT региона vs LMT места).
- **Дома:** Placidus по умолчанию. Для высоких широт (>66°) — Whole-Sign.
- **Аспекты:** только мажорные. Минорные — отложены.
- **Лилит:** Mean Apogee (классический Black Moon).
- **Узлы:** True Node.

## Что подтвердилось тестом Юнга

Sun + Moon точны до 0.5°:
- Sun: Leo 3.32° ✅
