# 2026-05-17 — Запуск проекта astro-bot

## Что это

Новый проект: Telegram-бот персональной астрологии в стиле Co-Star. Полная спецификация в `docs/PRODUCT.md`, тон в `prompts/TONE.md`, roadmap в `docs/ROADMAP.md`.

## Ключевые решения

- Позиционирование: жёсткий ироничный тон, минималистичный визуал, ориентация на образованных женщин 20–40
- Главный retention-механизм: ежедневный персональный push в 8:00 (Premium)
- Главный growth-механизм: виральная функция совместимости
- Монетизация: подписка 399₽/мес + pay-per-reading + реклама в канале
- Стек: Node.js + Telegraf + Supabase + Railway + Claude API (Sonnet 4 + Haiku 4.5)
