# 2026-05-18 — task-101 закрыта (скаффолдинг)

## Что сделано

Базовый каркас бота. Запускается, отвечает на команды, проходит typecheck. Не подключён к реальной БД — это нормально для скаффолдинга.

## Стек, который зафиксирован

- **Node.js 20+** (разработка на 22.22)
- **TypeScript 5.7**, strict + noUncheckedIndexedAccess
- **ESM модули** (`"type": "module"` в package.json, `.ts` импорты)
- **tsx** для dev (watch + hot reload), нативная Node 22 strip-types для prod-варианта
- **Telegraf 4.16** для Telegram
- **@supabase/supabase-js** 2.45 для БД
- **@anthropic-ai/sdk** 0.30
- **pino** + pino-pretty для логов

## Структура

```
src/
├── bot/index.ts          ← createBot(), Telegraf setup, /start /chart /help
├── bot/onboarding.ts     ← handleStart() c приветствием в фирменном тоне
├── astro/chart.ts        ← интерфейсы NatalChart/PlanetPosition/Aspect + stub calculateChart()
├── llm/claude.ts         ← Anthropic client + CLAUDE_MODELS (sonnet-4-6 + haiku-4-5)
├── db/client.ts          ← Supabase client (service_role)
├── db/migrations/0001_initial_schema.sql  ← все 7 таблиц по STACK.md
├── utils/config.ts       ← env-валидация с required()/optional()
├── utils/logger.ts       ← pino с pretty в dev
└── index.ts              ← точка входа, launch/webhook, graceful shutdown
```

## Принципы, зафиксированные в коде

- `config.ts` падает на старте, если нет обязательных переменных — fail fast
- `feedback_anthropic_api_key_must_be_unset` — отражён в .env.example комментарием
- Telegram replies через `.replyWithHTML()` — не MarkdownV2 (см. auto-memory)
- Graceful shutdown по SIGINT/SIGTERM
- Webhook режим автоматически выбирается в production, long-polling в development
- TypeScript strict с `noUncheckedIndexedAccess` и `verbatimModuleSyntax` для надёжности
