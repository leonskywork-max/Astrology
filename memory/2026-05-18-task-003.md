## Важный урок (для всех будущих task'ов проекта)

Проверка свободности username **только через t.me не работает** — Telegram возвращает stub-страницу для имён на аукционе fragment.com. При попытке создать канал отказывает.

**Правильная методика:**
1. `curl t.me/<username>` — занят, если есть `tgme_page_title`
2. `curl fragment.com/username/<username>` — если есть статус (Available/Sold/Taken/For Sale) — это коллекционное имя, занять обычным способом нельзя
3. Реально свободен = НЕ на fragment + НЕ на t.me

При первом проходе я предложил Леону @numen, он попробовал — Telegram отказал. Тогда сделали ещё 3 круга проверки (150+ username) с двойной верификацией.

**Главный вывод:** все короткие "красивые" 5-7 буквенные англоязычные имена в Telegram запасены fragment.com. Реально свободны — только длинные составные, неологизмы или редкие латинизмы.
