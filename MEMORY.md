# MEMORY — ключевые решения проекта Numen

Индекс главных решений. Подробности — по ссылкам.

## Название

**Numen** (лат. "знак свыше, божественный кивок"). Выбрано 2026-05-18 из 30 вариантов в task-003.
- Канал: **@numen** (свободен в Telegram на момент выбора — требует ручной верификации перед резервацией)
- Бот: предположительно **@numenapp** (свободен) или **@numen_bot** (занят, нужно альтернатива)
- Альтернативы топ-3 на случай: Natal, Transit, Liminal — все со свободным `@name`

## Позиционирование

**"Co-Star на русском"** — острый персональный голос против wellness-приторности всех остальных астроконкурентов. Полная спека: [docs/POSITIONING.md](docs/POSITIONING.md). Решение зафиксировано 2026-05-18 в task-002.

## Целевая аудитория

Городские женщины 22–35, ироничные, читают каналы вроде "Гороскоп и Кирилл" и "Ретроградный Меркурий", но хотят персональное, а не общее.

## Монетизация

- Premium: **399₽/мес** или 2990₽/год. Триал 7 дней.
- Pay-per-reading: 299–999₽.
- Реклама в канале: только с 10K+ подписчиков.
- На снижение до Natalon-уровня (100₽) не идём — цена оправдывается голосом и виралкой.

## Голос

См. [prompts/TONE.md](prompts/TONE.md). Жёсткий, ироничный, прямой, без эзо-лексики. Эталон — Co-Star, адаптированный под русскоязычную культуру.

## Стратегия запуска

Канал и бот публикуются **только после MVP**. До этого — никаких публичных выходов. Резерв username — отдельное решение.

## Конкуренты — топ-3 прямых угроз

См. [knowledge/competitors.md](knowledge/competitors.md). Главный риск — Гороскоп и Кирилл (~197K) или Ретроградный Меркурий (~33K) могут запустить бота и закрыть щель.

## Стек

- Node.js + Telegraf
- Supabase (PostgreSQL + auth + storage)
- Railway (деплой)
- Claude API (Sonnet 4 для качества, Haiku 4.5 для массовости)
- swisseph для астрорасчётов
- Telegram Stars + ЮKassa для платежей

Полная спека стека: [docs/STACK.md](docs/STACK.md).
